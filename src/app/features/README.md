# Features

`features` contains user-facing product areas. Each feature owns the pages, local components, and UI flow for one part of Sloty.

Current Sprint 0 feature folders:

- `auth`: login and future authentication screens.
- `dashboard`: the future operational dashboard entry point.

Future feature folders should follow the same pattern for bookings, clubs, courts, transactions, and settlements. Keep feature code focused on UI and frontend state; do not invent backend API contracts in the frontend.
