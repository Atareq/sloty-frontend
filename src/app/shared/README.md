# Shared

`shared` contains reusable frontend pieces that are not tied to one Sloty business feature.

Use this folder for:

- Presentational components such as cards, buttons, headers, and chips.
- Generic directives, pipes, and utilities.
- Small UI helpers that can be used by many feature pages.

Shared components should stay simple and typed. They should not fetch data, store authentication state, or contain booking, transaction, club, court, or dashboard business logic.
